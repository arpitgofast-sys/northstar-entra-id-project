# northstar-entra-id-project

# Identity Lifecycle & Access Governance for Northstar Consulting

## Project summary
This is a personal Microsoft Entra ID lab built for a fictional 120-person consulting company, Northstar Consulting Pvt Ltd.

The project demonstrates identity lifecycle management, group-based access, least-privilege administration, MFA/security controls, enterprise application onboarding, B2B guest access, audit evidence, and Microsoft Graph PowerShell automation.

## Lab boundary
- Personal Microsoft Entra tenant only
- Fictional users and fictional business data only
- No office tenant, company data, company accounts, credentials, or secrets
- Entra ID Free is used for the core project
- P1/P2 features will be clearly marked as optional trial-based work
